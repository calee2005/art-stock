# F11 冲突处理 UI

## 目标

在全局锁之外，处理「离线分叉」：展示冲突分支、比较元数据、选择保留一方或双方。

## 冲突来源

| 类型 | 产生条件 | 存储 |
| --- | --- | --- |
| 画稿/文稿/导图内容 | 同一分支两个不同 parent 的 snapshot | `conflict/{deviceId}-{hlc}` 分支 |
| 标量 | 少见（锁内 LWW 已自动） | 不弹窗 |
| 数据表同单元格 | 比较流程中发现 | UI 选择，不自动建分支 |
| 树环 / 非法 op | 合并拒绝 | 队列项标记 failed |

## UI

- 全局「冲突」徽章：数量 = 未处理 conflict 分支 + failed ops。
- 画稿冲突页：左右预览（图或文本）、当前分支 vs conflict 分支；操作：
  - **采用远端**：删除或归档 conflict 分支（指针不动）。
  - **采用本地**：把原分支指针改到 conflict 的 snapshot（持锁）。
  - **保留双方**：把 conflict 分支重命名为用户指定名，留在列表。
- 元数据只读对比表：名称、标签、更新时间、设备。
- 强制解锁入口放在同步状态，不放在本页主路径。

## 同步

处理冲突的写操作同样 `withRemoteLock`。不得在未获锁时改 branch 指针。

## 验收

- 构造分叉后徽章出现，处理三种操作后远端分支状态符合描述。
- 未处理时不静默丢任何 snapshot。
- Pad 上冲突页可完成「保留双方」。

## 非目标

- 像素级图像 merge。
- 三路自动合并 Markdown（可后置，首版选边）。
