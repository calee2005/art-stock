# F07 PDF 查看

## 目标

在客户端内查看 PDF 页面并翻页。只读，不提供注释首版。

## 对象模型

`type: "pdf"`。blob 为 PDF 字节。元数据可缓存 `pageCount`（解析后回写 meta，LWW）。

## UI

- 内嵌 pdf.js（或同等）：上一页 / 下一页 / 页码 / 缩放。
- 未下载原文件时显示缩略图或首页渲染占位，并提供「下载以查看」。
- Pad：滑动翻页；避免与壳层手势冲突（边缘返回除外）。

## 同步

按 Pin / 按需 GET。查看本身不写远端。若解析 `pageCount` 后更新 meta，则走普通持锁同步。

## 验收

- 打开 ≥2 页 PDF，翻页与页码一致。
- 未钉选时先不拉全文件，点开后再拉。
- Web 与桌面都能看（同源协议加载 blob，注意 pdf.js worker 打包）。

## 非目标

- 填写表单、签名、注释同步。
- OCR。
